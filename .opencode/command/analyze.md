## Создай файл для работы с вопросом

Создай файл problems/{название вопроса на английском через дефис}.md
Добавь в файл заголовок первого уровня с названием вопроса.
Добавь в файл раздел второго уровня "Поставленный вопрос" и с текстом оригинального вопроса.

## Развёрнутый вопрос

Переформулируй проблему максимально точно и вырази её одним развернутым предложением. Запиши результат в файл разделом второго уровня под названием "Развернутый вопрос".

## Краткое описание проблемы

Составь краткое описание проблемы в 5–10 предложений. Опиши суть философского вопроса. Расскажи, почему вопрос не тривиален. Объясни, где именно возникает напряжение. Запиши результат в файл разделом второго уровня под названием "Краткое описание".

## Философские позиции по этому вопросу

Распиши все существующие философские позиции по этому вопросу. Объясни, где именно возникает напряжение. Запиши результат в файл разделом второго уровня под названием "Философские позиции". Для каждой позиции распиши

### Формулировка позиции

- Краткое и чёткое описание
- Что утверждается
- Что отрицается

### Примеры

- Простой для понимания житейский пример
- Интеллектуальный / мысленный эксперимент

### Генезис позиции

- Как люди пришли к этой позиции
- Какие проблемы она пытается решить

### Аргументы в пользу позиции

- Основные аргументы
- Скрытые предпосылки
- Неявные переходы

### Проверка логической корректности

- Внутренняя согласованность
- Возможные логические ошибки
- Есть ли подмена тезиса, круг в аргументации, скрытые допущения?

### Метафизические утверждения (экзистенциальная ставка)

- Какие метафизические утверждения делает позиция
- Что «ставится на кон» экзистенциально
- Что позиция молча предполагает о реальности

## Критика философских позиций

### Общая критика

- Вопросы, которые позиция не может решить
- В чём слабость позиции

### Перекрёстная критика

- Как эту позицию критикуют другие позиции
- Простые, наглядные примеры

### Доведение позиции до абсурда

- Предельный случай
- Где позиция ломается
- Что происходит, если принять её до конца
