Вопрос для анализа: $ARGUMENTS

# Сделай следующие шаги пошагово

- Напиши текст оригинального вопроса
- Кратко описаши проблему. Опиши суть философского вопроса. Расскажи, почему вопрос не тривиален, в чём его парадоксальность. Объясни, где именно возникает напряжение.
- Распиши основные философские позиции по этому вопросу. Для каждой позиции распиши её полнословное и понятное описание, что она утверждает, что отрицает. Опиши логику того, как люди пришли к этой позиции.
- Для каждой позиции приведи простой для понимания пример или мысленный эксперимент, в котором раскрывается суть позиции.
- Для каждой позиции распиши, какие метафизические следствия из неё следуют.
- Для каждой позиции полнословно и понятно распиши основные аргументы в их пользу.
- Для каждой позиции распиши, согласована ли она внутренне и какие в ней могут быть возможные логические ошибки, нет ли там подмены тезиса, круга в аргументации или скрытых допущений?
- Для каждой позиции распиши её слабые места, раскритикуй нелогичности. Опиши вопросы, на которые с этой позиции нельзя ответить.
- Доведи каждую позицию до абсурда, до предельного случая.
- Раскритикуй вопрос с точки зрения буддийской прасанги.
- Напиши диалектический спор между абстрактными представителями разных позиций. Персонажи = позиции. Каждый отвечает строго из своей логики. Никакого «мудрого судьи» сверху. Каждый персонаж в ходе диалога должен много говорить.
- Попробуй найти позицию за пределами сформулированных позиций - сделай синтез всех тезисов и антитезисов. Понятно и просто опиши результат.
- Попробуй сформулировать апорию, связанную с поставленным вопросом.
- Сформулируй какой метавопрос можно задать о поставленном вопросе.
- Попробуй сделать неожиданный философский ход: инверсию предпосылки, рефрейминг проблемы, смену онтологического уровня или подрыв исходного различия. Опиши, как иначе можно поставить вопрос. Что исчезает и что появляется при этом?
- Распиши свои собственные мысли по данному вопросу.

Пиши много, не используй списки. Результат запиши в папку analysis в виде MD-файла с названием английскими буквами, соответствующему вопросу.
