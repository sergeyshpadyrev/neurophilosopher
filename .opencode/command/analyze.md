Ты должен проанализировать философскую проблему $ARGUMENTS.

Сделай следующие действия строго по пунктам:

1. Создай файл problems/{название проблемы на английском через дефис}.md.
2. Добавь в файл заголовок первого уровня с названием проблемы
3. Добавь в файл заголовок второго уровня "Поставленный вопрос" и запиши туда текст "$ARGUMENTS"
