# Нейрофилософ

Работает на основе Open Code.

## Запуск

```
opencode
```

## Команды Open Code

### Анализ

Анализирует философский вопрос со всех сторон

```
/analyze существуют ли в онтологическом смысле квалиа
```

### Дискуссия

Пишет диалектических спор по ролям исторических философов на заданную тему

```
/discuss существуют ли в онтологическом смысле квалиа
```
