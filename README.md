# Нейрофилософ

Работает на основе Open Code.

## Запуск

```
opencode
```

## Команды Open Code

### Анализ

Анализирует философский вопрос со всех сторон

```
/analyze реальность квалиа
```

### Дискуссия

Пишет диалектических спор по ролям исторических философов на заданную тему

```
/discuss реальность квалиа
```

### Критика

Критикует написанный вами текст

```
/criticize реальность квалиа
```

### Выйти за рамки

Пытается выйти за рамки вопроса и поставить мета вопрос

```
/reframe реальность квалиа
```

### Прасанга

Анализирует философский вопрос с помощью метода прасанги Нагарджуны

```
/prasanga реальность квалиа
```
